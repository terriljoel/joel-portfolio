# Projects

## Contrail Analysis (Contrail MVP)
- Built an end-to-end MVP to estimate contrail formation risk by merging OpenSky flight trajectories with ERA5 pressure-level weather.
- Engineered flight segmentation, RHi/ISSR physics scoring, and counterfactual altitude analysis (UP/DOWN) for per-flight recommendations.
- Delivered a Streamlit UI to guide data download, processing, scoring, and optimization workflows.
- GitHub: [contrail-analysis](https://github.com/terriljoel/contrail-analysis)
